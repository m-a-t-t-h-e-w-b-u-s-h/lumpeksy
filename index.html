    Klucz Google Maps

    Opcjonalnie, zamiast darmowych map. W Google Cloud Console utwórz klucz i włącz: Maps JavaScript API, Places API (New) oraz Routes API. Google wymaga włączonych płatności. Klucz zostaje tylko w tej przeglądarce.

    Dane mapy: © współtwórcy OpenStreetMap (popraw mapę). Wyszukiwanie: Nominatim. Trasy pieszo i rowerem: FOSSGIS. Komunikacja: Transitous i jego źródła. Kafelki: © CARTO. Kod i kontakt: GitHub (licencja MIT). Po zalogowaniu lista sklepów jest przechowywana w Google Firebase.
