Lumpeksy

Wpisz np. „second hand Wrocław” albo adres sklepu. W OpenStreetMap nie ma wszystkich lumpeksów, więc jeśli sklepu nie ma, wyszukaj jego adres.

Lista pochodzi z OpenStreetMap i wroclaw.pl, więc może być niepełna albo nieaktualna. Sklepy trafią do działu „Do oceny” i wejdą do trasy dopiero po ocenieniu.

Suma ocen

    Klucz Google Maps

    Opcjonalnie, zamiast darmowych map. W Google Cloud Console utwórz klucz i włącz: Maps JavaScript API, Places API (New) oraz Routes API. Google wymaga włączonych płatności. Klucz zostaje tylko w tej przeglądarce.

    Dane mapy: © współtwórcy OpenStreetMap (popraw mapę). Wyszukiwanie: Nominatim. Trasy pieszo i rowerem: FOSSGIS. Komunikacja: Transitous i jego źródła. Kafelki: © CARTO. Lista lumpeksów z Wrocławia: OpenStreetMap i wroclaw.pl. Kod i kontakt: GitHub (licencja MIT). Po zalogowaniu lista sklepów jest przechowywana w Google Firebase.
